# Ethical Hacking and Information Security Assessment Project

## Overview

This project presents an ethical hacking and information security assessment for a simulated healthcare environment, Blue Cross Hospital.

The project examines cybersecurity threats, vulnerabilities, network services, penetration testing techniques and defensive security measures used to protect sensitive organisational information.

## Project Objectives

- Analyse suspicious files using static and dynamic malware analysis
- Identify spear phishing attacks and appropriate security controls
- Investigate vulnerabilities affecting organisational systems
- Assess SNMP and other network services
- Perform operating system fingerprinting and reconnaissance
- Analyse insecure FTP communication using Wireshark
- Evaluate Windows privilege escalation vulnerabilities
- Examine footprinting and online reputation risks
- Recommend security controls and countermeasures
